## Keeping the PRD in sync

The PRD is edited in its live doc:
[Kloudboy Software Factory — PRD](https://claude.ai/artifact/99LJ6dRJLy7jtBgmTPV1eB).
`PRD.md` here is the copy coding agents read. When the live doc changes, update `PRD.md` in the
same change, and note anything that changed a decision in `decisions.md`.
