# kloudboy-plugins

Kloudboy's private Claude Code plugin marketplace.

| Plugin | What it does |
| --- | --- |
| [factory](plugins/factory/README.md) | Software factory: spec → plan → build → test → review, with gates and a dashboard |

## Install

```
/plugin marketplace add <this repo's git URL or local path>
/plugin install factory@kloudboy
```

Then, in each project: `/factory:init`.
